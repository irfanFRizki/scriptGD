# scriptGD
Kumpulan Script Google

Dokumentasi rancangan dan analisis arsitektur untuk pengembangan APK Dashboard Android (Kotlin / Jetpack Compose) disimpan di folder `docs/`:
- `docs/SOURCE_ANALYSIS.md` — Analisis source code GAS (`Code.gs` dan `Index.html`).
- `docs/ARCHITECTURE.md` — Arsitektur teknis dan alur integrasi Google API.
- `docs/DASHBOARD_UI_DESIGN.md` — Rancangan awal UI dashboard.
- `docs/OAUTH_SECURITY.md` — Standar keamanan OAuth, token, dan mitigasi risiko.
- `docs/SECURITY_REVIEW.md` — Hasil evaluasi keamanan dan threat model dari timses.
- `PROJECT_CONTEXT.md` — Catatan konteks dan keputusan proyek.
